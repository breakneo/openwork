Guide
Read purpose, delivery and dev status, then compare the outcomes beside Approve and Decline; raw evidence is collapsed below.
OFFLINE records intent only, with no network. LIVE sends each new decision once for owner recheck; imports and offline Undo last stay disabled. Use Undo decision or Change decision in the log or decided card: queued withdrawal wins only before claim, running cannot be interrupted, archived work needs unarchive, sent messages need a reviewed follow-up, and merges are not reversible. Unconfirmed delivery is local only or uncertain: inspect the thread, never replay exported decisions. Live JSON and Markdown are audit-only records with receipts and local uncertainties: actions may already have executed, and these files cannot be restored as decision feeds. Live drafts and pending audit entries recover locally without resending. Later is local to this browser and sends nothing. Messages are independent of approve/decline and do not cancel or stop work. The legacy explicit stop protocol remains supported by the executor; ordinary message text is never a hidden control.
Focus a card: j moves next, ArrowUp moves previous, a approves, x archives, k keeps (d is a legacy alias), l skips locally to Later, c / ? opens the message, Cmd/Ctrl+Enter sends it, Space selects. Shortcuts pause in controls and dialogs; Undo reverses the last batch only offline. Export JSON for backup; offline restore requires the exact source snapshot.
